# Ejercicio 4 - Card con CSS Grid

## Descripción

Este ejercicio consiste en la creación de una card utilizando CSS Grid.

El objetivo es demostrar el uso de Grid para estructurar y alinear los elementos internos de una tarjeta de contenido.

## Estructura de la card

La card está compuesta por:

- Imagen superior
- Título
- Texto descriptivo (lorem ipsum)
- Fecha de publicación
- Botón de acción
