# Ejercicio 3 - Navbar responsive con Flexbox

## Descripción

Este ejercicio consiste en la creación de una barra de navegación utilizando Flexbox.

El objetivo es construir un navbar adaptable que cambie su disposición según el tamaño de pantalla mediante media queries.

### Resoluciones mayores

- Navbar en una sola fila
- Logo a la izquierda
- Menú alineado a la derecha
- Distribución horizontal de los items

### Resoluciones menores

- Navbar en formato columna
- Menú apilado verticalmente
- Cada item ocupa el ancho completo
